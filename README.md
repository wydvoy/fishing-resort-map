# Fishing Resort Spawn Map

Interactive zone map for Fishing Resort (Wii). Pick an area, pick a time of day, hover a zone to see which fish spawn there and how likely each one is. Search a species to light up every zone it can spawn in.

Live page: https://wydvoy.github.io/fishing-resort-map/

Unofficial fan project. Not affiliated with or endorsed by the game's publisher or developer. Fonts: Lilita One and Plus Jakarta Sans (SIL Open Font License, see `fonts/`).
