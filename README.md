# Fishing Resort Spawn Map

Interactive zone map for Fishing Resort (Wii). Pick an area, pick a time of day, hover a zone to see which fish spawn there and how likely each one is. Search a species to light up every zone it can spawn in, with its favourite lure colour, best lures and bait for each weather.

The Mechanics page explains how fishing works: spawning, bites, lure colour, bait, size and rank, tackle, trolling, weather and the calendar. Its tables are in `data/` as CSV.

Live page: https://wydvoy.github.io/fishing-resort-map/

Mechanics research by [kyuuri1234](https://github.com/kyuuri1234/FishingResortData) (CC0), ported to the USA disc and re-checked. Thank you!
